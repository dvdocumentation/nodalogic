{% if is_en %} NodaLogic is a low-code platform built around one primitive — the node. {% if is_en %}Node is the basic unit{% else %}Узел — основа логики{% endif %}

{% if is_en %}A node combines persistent state, class methods, events and links to other nodes. Business entities and processes are built from the same simple unit.{% else %}Узел объединяет постоянное состояние, методы класса, события и связи с другими узлами. Из одного простого элемента строятся и бизнес-сущности, и процессы.{% endif %}

{% if is_en %}Independent mobile runtime{% else %}Независимая мобильная платформа{% endif %}

{% if is_en %}Android clients can store data and execute node logic locally, continue offline and synchronize when connectivity is available.{% else %}Android-клиенты могут локально хранить данные и исполнять логику узлов, продолжать работу без связи и синхронизироваться при её появлении.{% endif %}

{% if is_en %}Execution follows the node{% else %}Исполнение следует за узлом{% endif %}
